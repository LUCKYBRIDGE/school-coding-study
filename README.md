# school-coding-study

학교 수업용 코딩·AI·정보교육 웹앱과 도구를 분석하고, 수업 설계와 자체 구현에 재사용할 수 있는 구조적 지식을 정리하는 리포지토리입니다.

## 분석 원칙

- **Evidence-first**: 실제 화면과 공개된 문구에서 확인되는 사실을 우선 기록합니다.
- **관찰 / 명시 / 추정 분리**: 사이트에서 직접 확인한 내용과 기술적 추론을 섞지 않습니다.
- **재구현 관점**: 기능 목록만 적지 않고 상태 흐름, 데이터 구조, 알고리즘, UI 패턴까지 분해합니다.
- **교육적 검토**: 2022 개정 교육과정 성취기준과 실제 학생 활동의 연결을 함께 봅니다.
- **학교 환경 관점**: 계정, 개인정보, 카메라, 네트워크 의존성, 인쇄, 저사양 기기 사용성을 확인합니다.

분석 방법은 [storytold/craft-anything](https://github.com/storytold/craft-anything)의 Study → Build → Check 관점 중 **Study / evidence-first investigation** 아이디어를 참고합니다.
