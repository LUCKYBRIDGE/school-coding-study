- 사용 프레임워크

# 10. Craft Anything 관점 적용

참고:
https://github.com/storytold/craft-anything

Craft Anything은 웹사이트 분석에서

- 보이는 화면
- 텍스트
- 레이아웃
- 상태 변화
- 동작
- 근거와 확실성

을 구분해 조사하는 evidence-first 방식을 강조합니다.

이번 분석에서도 이 관점을 적용해

```
관찰
→ 기능 분해
→ 상태 추론
→ 알고리즘 가설
→ 독립 재구현 명세
```

순으로 정리했습니다.

원본 내부 코드를 확보하지 못한 부분은 추정으로 명시했고, 확인되지 않은 라이브러리나 함수 이름은 만들어내지 않았습니다.
